11.1.2 +CESQ, Extended Signal Quality

Description

Execution command returns received signal quality parameters.

<ber> always return 99.

If the current serving cell is in GSM/UMTS/LTE/C2K/ENDC/NR cell ， <rxlev> will return
normal ,else return 99.

If the current serving cell is in UMTS cell, <rscp>, <ecno> will return normal, else return 255.

If the current serving cell is in /LTE/C2K/ENDC cell, <rsrq>, <rsrp> will return normal, else
return 255.

Only the current serving cell in ENDC/NR cell, <ss_rsrq>, <ss_rsrp>and<ss_sinr> will return
normal, else return 255
